BA2026 E-Portfolio — GitHub Pages

This folder contains the ready-to-publish website:
- index.html

To publish it:
1. Sign in to https://github.com/
2. Create a new public repository, e.g. ba2026-eportfolio
3. Choose Add file → Upload files
4. Upload index.html from this folder and commit the changes
5. Open repository Settings → Pages
6. Under Build and deployment, choose Deploy from a branch
7. Select branch main and folder /(root), then Save
8. Wait a minute or two. GitHub will show the public website URL in Settings → Pages.

You do not need to paste the HTML into Google Sites or resize an embed.
